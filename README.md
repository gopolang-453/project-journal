# Project Journal

Personal blog and documentation site for my projects.

Built as a static site and hosted on GitHub Pages.

## Live Site

Once GitHub Pages is enabled, visit: https://gopolang-453.github.io/project-journal/

## How to enable GitHub Pages

1. Go to the repository Settings
2. Click Pages in the left sidebar
3. Under Source, select Deploy from a branch
4. Choose main branch and / (root)
5. Save

The site will be live at the URL above within a minute or two.
